# Metadata grabbing
## Code
The code is incredibly simple. Using the library music-metadata, the code simply  
passes the file location of the .mp3 you want to grab the metadata from. Then  
the code simply runs some basic commands in the return to aptly return the  
values from the file.  

## Utilization
Not present in the current state, but in future sprints, functionality for  
the database or server (still in works) to be able to call the function,  
grab the data, and store it for when the client wants to show it to the  
user will be implemented.
